# 🎓 Student Portfolio Management System

A web-based application that allows students to upload, manage, and showcase their academic portfolios, including projects, awards, and extracurricular activities.
Admins can review, approve, or reject submissions, ensuring quality and credibility.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, JavaScript  
- **Backend:** PHP (PDO)  
- **Database:** MySQL

## ✨ Features

- Student registration and login  
- Role-based access (Admin, Student)  
- Upload and manage portfolio items (projects, awards, certificates)  
- Admin approval and rejection of entries  
- File upload and download functionality  
- Responsive UI with Bootstrap  
- Secure database interactions using PDO
